# Changelog

## 0.2.0
- `report` and `suggest` commands: summarize a log and draft an allowlist from observed traffic.
- Blocked connections now print a visible notice; close records keep the true decision.
- `version` command, `make STATIC=1`, Dockerfile, Docker Compose enforcement example.
- GitHub Action for the config scanner, CI on Linux and macOS, release workflow with checksums.

## 0.1.0
- First prototype: allowlist proxy, private-address blocking, hash-chained audit log, `run`/`proxy`/`check`/`verify`.
